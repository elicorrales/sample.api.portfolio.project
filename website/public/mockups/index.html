Web client mockups

Five looks for the admin web client. Each shows the same two screens, the users list with one user open for editing, and the checks that make the API refuse things, so only the look and layout differ. These are static pictures, not the app.

  • AClean internal toolLight, one blue for actions, edit panel on the right, checks as a list with the last response beside it. Inter.
  • BDeveloper consoleDark slate, three panes like an editor, every request and response always visible. IBM Plex Sans and JetBrains Mono.
  • CEngineering notebookGreen grid paper and ink; checks written as experiments with a claim, a prediction, and a stamped result. Newsreader and Spline Sans Mono.
  • DDense back-office gridSmall type, a full page of rows, editing inside the row, checks docked at the bottom. IBM Plex Sans Condensed.
  • EBold modernBig type, thick black lines, flat bright color; each check is a tile led by the status code it forces. Space Grotesk.
